## v0.20.0 — cloud sessions that set up their own git identity, and no more attribution lines by default

### `agtk cloud init` sets the git identity and signing key of a cloud session

A cloud container starts with no git identity and no signing key. `agtk cloud init` reads them from
the environment and configures git:

- **`AGTK_GH_USER` and `AGTK_GH_EMAIL`** set `user.name` and `user.email`.
- **`AGTK_SIGNING_KEY_B64`** is a base64-encoded SSH private key. When it is set, commits and tags
  are signed with it, so they show as Verified on GitHub. The key is checked with `ssh-keygen` and proved
  able to sign before the signing settings are written, so a value that is not a usable key fails
  without enabling signing.
- **With none of the three set, the command does nothing** and prints one line saying so.
- **`--render`** also runs `agtk render` (never `sync`, so no ref is resolved over the network) in
  every directory directly under `--render-root` (default `/home/user`) that has an
  `.agentic-toolkit.yaml` and a lockfile committed at `HEAD`. Rendered output is gitignored, so a
  fresh clone has none until something renders it. A checkout that fails to render is named in
  one error that lists all of them.

### The default stack runs it at session start

`stacks/default.yaml` now carries a `SessionStart` hook (`cloud-init-claude-session-start`) that
runs `agtk cloud init --render`.

- **It does nothing unless one of the three variables is set.** On a local machine, or in a
  container without them, it prints one line and exits.
- **It never blocks a session.** A failure prints a `Note:` and exits 0, and the hook has a
  600-second timeout.
- **An older `agtk` is skipped silently.** The hook checks that the installed binary knows
  `--render` before using it.

`docs/CONSUMER-GUIDE.md` gains an environment recipe for a cloud container: the variables to set,
the setup script, and what to check after the first session.

### Claude Code no longer adds attribution to commits, pull requests and session links

A new `no-attribution` stack switches off the `Co-Authored-By` trailer on commits, the "Generated
with" line on pull requests and the session link. `stacks/default.yaml` extends it, so a consumer on
the default stack gets it in local and cloud sessions alike. It is Claude-only, and adoptable on its
own by listing `no-attribution.yaml`. The setting is project-scope: a higher scope can still
override it.

### `context7` is no longer in the default stack

**Breaking for consumers who relied on it.** `stacks/default.yaml` no longer lists the Context7 MCP
server. It now lives in `stacks/context7.yaml`, which a consumer adds to `extends:` to get it
back. Serena is not rendered in this repository any more either; `stacks/serena.yaml` is unchanged.

### Also in this release

- `agtk update` replaces the running binary itself instead of through `minio/selfupdate`, which
  removes that module and the `golang.org/x/crypto` modules it pulled in, along with the open
  `openpgp` advisory against them. The checksum verification and the atomic rename are unchanged.
- `agentic-driver` v0.10.0 → **v0.10.1**, which drops the gpg dependency.
- The Go toolchain moves to 1.26.9, which carries fixes for 13 standard-library advisories.
- A new `approach-selection` instruction is in the catalog. No stack lists it, so it renders
  nowhere until a consumer lists it.
- `CONTEXT.md` defines **Harness** and **Transcript** for the usage work. An internal `usage`
  package parses Claude Code transcripts into usage rows; nothing in the CLI calls it yet.

### Compatibility

- **No schema changes.**
- **What `stacks/default.yaml` renders changes for existing consumers:**
  - `attribution` settings appear in `.claude/settings.json`;
  - a `SessionStart` hook appears;
  - the Context7 MCP server disappears from `.mcp.json`.
- **The hook and the binary go together.** Upgrade `agtk` before, or in the same step as, moving
  the ref. An older binary skips the hook silently and does not render checkouts.
- **Action for existing consumers:** `agtk update` (or re-run `install.sh`). Consumers pinned to a
  tag can bump the ref in `.agentic-toolkit.yaml` to `@v0.20.0`. A consumer that wants Context7 adds
  `github.com/pedromvgomes/agentic-toolkit/stacks/context7.yaml@v0.20.0` to `extends:`.
- **Building from source requires Go 1.26.9.**
