## v0.17.0 — gt 2.0.0, Opus 5.5, and a handoff that converges the pull request it opens

### This repository is now governed by gt 2.0.0

`.gt-repo.yaml` tracked gt 1.7.0, which gated the pipeline with bulwark. gt 2.0.0 replaces that
gate with lydite: `ci-orchestration.yml`'s `bulwark` job is gone, replaced by a `lydite` job that
runs lydite's own referral/scan/test/publish pipeline rather than consuming a coverage artifact
this repository's own test job produced. `ci-test.yml` no longer builds or uploads a coverage
profile for a consumer that no longer reads one, and `.bulwark.yml` — the file that configured it
— is deleted along with it. A new `lydite-clearance.yml` workflow answers `/lydite clear` comments
on a pull request, the only way to unblock the `lydite/referral` check branch protection now
requires.

This repository's own `.lydite/` component declaration shipped ahead of this release, in #114.

### `opus` resolves to Claude Opus 5.5

`agentic-driver` v0.8.0 → **v0.9.0**. The `claudecode` provider's `opus` family alias now resolves
to `claude-opus-5-5` instead of `claude-opus-5`; a caller that has to stay on Opus 5 pins that
name explicitly rather than the alias. Nothing in `agtk` names a model directly — both providers
are constructed from PATH with no model configuration of their own — so this is a transparent
dependency bump: no schema, CLI, or definition change.

### `implement-handoff` delivers a mergeable pull request, not just a green one

Step 7 of the feature flow used to stop once its review loop came back clean and the checks it
waited on were green. It now goes further: a failed check is fixed on the branch (capped at three
rounds) instead of ending the run, a repository with a `.lydite/` directory has its referral read
and acted on (red is fixed even when lydite is not a required check; a pending referral while the
verdict is yellow is expected and not waited on), and merge conditions such as a branch that needs
rebasing are handled rather than left for a human to notice. Step 8 now closes the handoff only
once all of that holds. `docs/FEATURE-FLOW.md` matches.

### Compatibility

- **No schema changes, no CLI changes, no definition changes** beyond what `implement-handoff`
  does at steps 7–8.
- **Action for existing consumers:** `agtk update` (or re-run `install.sh`). Consumers pinned to a
  tag can bump the ref in `.agentic-toolkit.yaml` to `@v0.17.0`.
- **A repository governed by this project's own `gt` templates** picks up the bulwark → lydite
  switch the next time it runs `gt repo sync` against gt 2.0.0; it is not something `agtk` renders
  or enforces.
- **Building from source still requires Go 1.26.6.**
